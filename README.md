# Maternal Health Risk SQL Analysis

## Project Overview

This project presents a SQL Server analysis of maternal health risk using the Maternal Health Risk dataset.

The analysis focuses on descriptive statistics, risk-level distribution, and bivariate analysis of selected maternal health indicators.

## Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Dataset

The dataset contains 1,014 observations and includes the following variables:

- Age
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Blood Sugar
- Body Temperature
- Heart Rate
- Risk Level

## Analysis

The project includes:

- Data validation
- Data cleaning
- Descriptive statistics
- Risk-level distribution
- Bivariate analysis
- Findings and interpretation

## Key Findings

The analysis identified differences in maternal risk levels across categories of blood pressure, blood sugar, heart rate, body temperature, and age.

The findings are descriptive and do not establish causal relationships.

## Project Purpose

The purpose of this project is to demonstrate practical skills in SQL Server for health data cleaning, descriptive analysis, data summarization, and interpretation.
